# 设计文档

这里记录各个机制的**设计目的和约束**：为什么这么设计、踩过什么坑、改动时必须守住哪些不变量。不逐行讲实现——实现看代码，这里讲代码不会告诉你的那部分。

面向的读者是要改这个工程的人（包括 AI agent）。动某个机制之前，先读对应的那一篇。

## 写作约定

- 正文中文，代码/类名/路径/API/错误信息保持原文。
- 每篇开头列出涉及的源文件，方便从文档跳回代码。
- 优先写**为什么**和**不能怎么做**。会随代码漂移的细节（具体的方法调用链）尽量不写。
